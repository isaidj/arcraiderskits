## 2026-01-24 - Search Bar Keyboard Shortcut
**Learning:** Adding `Cmd+K` / `Ctrl+K` shortcuts to search inputs significantly improves navigation speed for keyboard users.
**Action:** When implementing search bars, add a keyboard listener for `Cmd+K`, focus the input, and display a visual hint (`⌘K`) when the input is empty to improve discoverability. Ensure the hint is hidden on mobile.
